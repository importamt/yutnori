# 윷놀이 · 사내 행사용 3D 윷판

오프라인에서 던진 윷 결과를 오퍼레이터가 입력하고, 퀴즈 칸에서 문제를 출제하는 행사 진행용 게임판입니다.
복셀(큐브) 캐주얼 테마: 잔디·나무·집이 있는 마을 광장 위에 윷판이 놓이고, 말은 팀 색 옷을 입은 큐브 캐릭터입니다.

## 판 읽는 법 (숫자 없음, 색으로 구분)

| 색 | 의미 |
|----|------|
| 흰 블록 | 일반 칸 |
| 노란 블록 | 퀴즈 칸 (도착 시 문제 출제, 정답 +2 / 오답 -2) |
| 하늘색 큰 블록 | 모서리·방 (정확히 멈추면 지름길) |
| 파란 큰 블록 | 출발/완주 |

## 실행

```bash
yarn            # 의존성 설치
yarn dev        # http://localhost:5173
yarn build      # dist/ 생성 → yarn preview 로 서빙
yarn test       # 규칙 엔진 테스트
```

## 진행 방법

1. **팀 설정** — 팀 수(2~12), 팀당 말 개수(1~4), 이름/색상 → 판 펼치기
2. **윷 입력** — 오프라인에서 던진 결과를 [진행] 탭 버튼 또는 단축키로 입력
   - `1`~`5` 도·개·걸·윷·모, `B` 백도, `0` 낙
   - 윷·모는 "한 번 더": 먼저 던져도, 먼저 움직여도 됩니다
   - 대기 결과를 여러 개 선택하면 합쳐서 한 번에 이동 (윷+개 = 6칸). 백도는 단독만
   - 낙은 그 던지기만 무효. 이미 나온 결과는 그대로 움직이고, 더 던질 수는 없습니다
3. **말 이동** — 선택지 버튼 클릭, 또는 판 위의 초록 표시(목적지)/뛰는 캐릭터 클릭
4. **퀴즈 칸(노란 칸 6·9·12·16·19·A2·B3)** — 도착 시 문제 출제. 팀이 말한 보기를 클릭 → 자동 판정 → `+2 적용` / `−2 적용`
5. `Z` 되돌리기, `Tab` 패널 숨기기(프로젝터용), `M` 음악 재생/정지

## 관리자 기능 (패널 하단 🛠 관리)

- **말 임의 이동**: 아무 말이든 아무 칸/대기/완주로 (외부 진행 상황 옮겨 담기)
- **판 클릭 모드**: 판 위 말 클릭 → 목적지 칸 클릭
- 차례 강제 변경, 한 번 더 부여, 대기 결과 삭제, 게임 종료/재개
- 퀴즈 수동 출제 (문제 지정 가능)
- 상태 내보내기/불러오기(JSON), 자동 저장(새로고침 후 이어하기)

## 문제 교체

`public/questions.json` 을 만들면 샘플 대신 자동으로 사용합니다. 형식은 `public/questions.example.json` 참고.
사진은 `public/quiz/` 에 넣고 `"image": "quiz/파일명.jpg"` 로 지정. 게임 중 🛠 관리에서 JSON 파일을 직접 불러올 수도 있습니다.

## 규칙 요약

- 바깥 20칸, 모서리(5·10)·방(C)에 정확히 멈추면 다음 이동에 지름길
- 상대 말이 있는 칸에 도착하면 잡고 한 번 더, 같은 팀 말은 업어서 함께 이동
- 출발점에 도착 또는 통과하면 완주
- 퀴즈 보너스(+2/−2)는 단순 이동: 재출제 없음, 잡기·업기는 정상 적용, 출발점 뒤로는 출발점에 머묾
- 백도는 지나온 길을 되돌아감 (1번 칸에서 백도 → 출발점에 대기)
